🎰 Gerador Estratégico para Lotofácil

Uma aplicação web leve e intuitiva desenvolvida em HTML5, CSS3 e JavaScript puro que gera palpites estratégicos para a Lotofácil com base na análise estatística dos últimos 10 concursos inseridos pelo usuário.

---

## 📌 Funcionalidades

- **Análise do Histórico:** Processa os dados dos últimos 10 concursos inseridos.
- **Frequência de Dezenas:** Mapeia e prioriza as dezenas mais e menos frequentes do histórico.
- **Controle de Repetição:** Gera jogos com **7 a 11 números repetidos** do último concurso (primeira linha inserida).
- **Equilíbrio de Paridade:** Filtra e valida os palpites para manter a proporção ideal de **7 Pares / 8 Ímpares** ou **8 Pares / 7 Ímpares**.
- **Interface Intuitiva:** Exibição clara dos números gerados no formato clássico de "bolas" com resumo das estatísticas do palpite.

---

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estruturação semântica.
- **CSS3:** Estilização moderna e responsiva baseada em Flexbox.
- **JavaScript (ES6+):** Manipulação de DOM, algoritmos de ordenação, amostragem e validação estatística.
